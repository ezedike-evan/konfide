# @konfide/adapter-privy

Implements the `Identity` port from `@konfide/core` using Privy auth + embedded wallets.

## Status

- [x] Port stubs in place (`PrivyIdentity`).
- [ ] Server-side token verification.
- [ ] Embedded-wallet provisioning on Solana.

## Env

- `PRIVY_APP_ID`
- `PRIVY_APP_SECRET`
